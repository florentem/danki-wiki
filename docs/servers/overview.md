# <span class="material-symbols-outlined">dns</span> Обзор серверов

Сеть состоит из нескольких серверов и миров, различающихся по правам использования команд и инструментов, специфике использования и порядку [получения доступа](../general/access.md) в них.

---

## <span class="material-symbols-outlined">lan</span> Серверы сети

* **[Сервер Лобби](./lobby.md)** — промежуточный сервер для удобного перехода между мирами сети через таблички на спавне (по ЛКМ или ПКМ при наличии прав).
* **[Сервер Комьюнити](./community.md)** — основной сервер проекта:
  * **Основной мир** — для обычного строительства (дом для [Pepeland](https://www.pepeland.net) с другом или командный проект); без прав на механизмы, чтобы ничего не мешало игрокам;
  * **Мир артов** — ячейки под карты как на [Pepeland](https://www.pepeland.net); созданные карты синхронизируются со всеми серверами сети;
  * **Архивные миры void и nosbworld** — сохранены как архивные для копирования построек в другие миры;
  * **Архивные миры Pepeland** — официальные неизменяемые сейвы 8 и 9 сезонов [Pepeland](https://www.pepeland.net) для просмотра и копирования построек без загрузки на ПК;
  * **Мир «Кошкиного дома»** — мир объединения «Кошкин дом» (доступ только для его участников).
* **[Сервер Редстоун](./redstone.md)** — сервер с полными правами для теста механизмов, ферм и механик в паритете с [Pepeland](https://www.pepeland.net). Включает плоский **Основной мир** (с ванильной бедроковой крышей в Незере) и пустое **Зеркало мира ферм Pepeland** (с сидом и структурами под биомозависимые фермы). Оснащён ботами (`/player`), счётчиками воронок, тиковыми зонами и командами Carpet ([подробнее об инструментах](../features/redstone-tools.md)). Не подходит для экстремально нагружающих ферм — для них лучше подходит одиночная игра.
* **[Сервер Лихтенштейн](./circle.md)** — более закрытый сервер для строительства проектов и ивентов более узким, одобренным кругом людей:
  * **Основной мир** — для обычного строительства с частичным функционалом тестов;
  * **Мир ивентов** — площадка Олимпийского комитета (строительство, промежуточные тесты, субботники).
