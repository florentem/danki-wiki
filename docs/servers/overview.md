# <span class="material-symbols-outlined">dns</span> Обзор серверов

Проект состоит из нескольких серверов, на каждом из которых несколько миров, различающихся по правам использования команд и инструментов, специфике использования и порядку [получения доступа](../general/access.md) в них.

---

## <span class="material-symbols-outlined">menu_book</span> Термины

| Термин | Значение | Не использовать для |
| :--- | :--- | :--- |
| **проект** | сеть серверов Danki целиком | отдельного сервера, постройки игрока |
| **сервер** | один бэкенд (Лобби, Комьюнити, Редстоун, Лихтенштейн) | всего проекта, хоста, Discord |
| **мир** | измерение или тройка измерений на сервере | «подмир» (термин исключён) |
| **измерение** | Верхний мир / Незер / Энд | целого мира |
| **постройка / работа** | то, что делает игрок | «проект» |
| **хост** | физическая машина или VPS | «сервер» |

---

## <span class="material-symbols-outlined">lan</span> Серверы проекта

* **[Сервер Лобби](./lobby.md)** — транзитный сервер для быстрого переключения между мирами проекта через таблички на спавне (по ЛКМ или ПКМ при наличии прав). Команда `/lobby <сервер>` перемещает на конкретный сервер проекта.
* **[Сервер Комьюнити](./community.md)** — основной сервер проекта:
  * **Основной мир сервера Комьюнити** (Верхний мир, Незер и Энд) — для обычного строительства (дом для [Pepeland](https://www.pepeland.net) с другом или совместная работа); без прав на механизмы, чтобы ничего не мешало игрокам;
  * **Мир артов** (Верхний мир) — ячейки под карты как на [Pepeland](https://www.pepeland.net); созданные карты можно переносить на другие серверы проекта через эндер-сундук ([инструкция](../features/features.md#husksync));
  * **Архивные миры void и nosbworld** (Верхний мир) — сохранены как архивные для копирования построек в другие миры;
  * **Архивные миры Pepeland** (сезоны 8 и 9; по 2 мира на сезон: мир ферм и мир построек 2, в каждом Верхний мир, Незер и Энд) — официальные неизменяемые сейвы [Pepeland](https://www.pepeland.net) для просмотра и копирования построек без загрузки на ПК;
  * **Мир «Кошкиного дома»** (Верхний мир, Незер и Энд) — мир объединения «Кошкин дом» (доступ только для его участников).
* **[Сервер Редстоун](./redstone.md)** — сервер с полными правами для теста механизмов, ферм и механик в паритете с [Pepeland](https://www.pepeland.net). Включает плоский **Основной мир сервера Редстоун** (Верхний мир, Незер и Энд; с ванильной бедроковой крышей в Незере) и пустое **Зеркало мира ферм Pepeland** (Верхний мир, Незер и Энд; с сидом и структурами под биомозависимые фермы). Оснащён ботами (`/player`), счётчиками воронок, тиковыми зонами и командами Carpet ([подробнее об инструментах](../features/redstone-tools.md)). Не подходит для экстремально нагружающих ферм — для них лучше подходит одиночная игра.
* **[Сервер Лихтенштейн](./lichtenstein.md)** — закрытый сервер для доверенного круга участников:
  * **Основной мир сервера Лихтенштейн** (Верхний мир, Незер и Энд) — для обычного строительства с частичным функционалом тестов;
  * **Мир ивентов** (Верхний мир, Незер и Энд) — площадка Олимпийского комитета (строительство, промежуточные тесты, субботники).
