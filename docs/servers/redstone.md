# <span class="material-symbols-outlined">precision_manufacturing</span> Сервер Редстоун

* **Команда для перемещения**: `/lobby redstone`

Сервер Редстоун — сервер с полными правами и инструменталом для теста механизмов, ферм и механик. По возможности сервер соблюдает паритет по механикам и настройкам с [Pepeland](https://www.pepeland.net).

::: tip Нагрузка и сложные тесты
Сервер всё ещё не подходит для тестирования очень нагружающих ферм или ферм, требующих полного функционала [Carpet](https://modrinth.com/project/TQTTVgYE) или других инструментов — для таких задач по-прежнему лучше подходит одиночная игра.
:::

## <span class="material-symbols-outlined">travel_explore</span> Подмиры сервера

### 1. Основной мир
* **Команда для перемещения в подмир**: `/worldtp main` (или `/dimension main`).
* Обычный плоский мир.
* Незер без стандартных блоков и биомов, но с крышей из бедрока сверху и снизу на идентичных ванильным высотах и идентичной толщины.

### 2. Зеркало мира ферм Pepeland
* **Команда для перемещения в подмир**: `/worldtp farm_mirror` (или `/dimension farm_mirror`).
* Мир с сидом генерации, совпадающим с актуальным миром ферм с [Pepeland](https://www.pepeland.net).
* Повторяет расположение биомов и структур, но полностью пустой как в Верхнем мире, так и в Незере.
* Структуры генерируются контурными боксами без блоков и мобов, по ним удобно размечать постройки (`/locate structure`, `/locate biome`).
* Полностью подходит для ферм, зависимых от биомов и естественного спавна, предназначенных для [Pepeland](https://www.pepeland.net).
