# <span class="material-symbols-outlined">castle</span> Сервер Лихтенштейн

* **Команда для перемещения**: `/lobby lichtenstein`

Сервер Лихтенштейн — более закрытый сервер проекта, предназначенный для совместных построек и ивентов более узким, одобренным кругом людей. 

Заявки в миры этого сервера не принимаются — участники добавляются в [закрытом порядке](../general/access.md#закрытый-порядок). На сервере Лихтенштейн представлены следующие миры, различающиеся по специфике использования (переключение командой `/worldtp <main|events>` или `/dimension`).

---

## <span class="material-symbols-outlined">public</span> Миры сервера

### 1. Основной мир
* **Состав измерений**: Верхний мир, Незер и Энд.
* **Команда для перемещения в мир**: `/worldtp main` (или `/dimension main`).
* Предназначен в первую очередь для обычного строительства.
* Присутствует частичный функционал для тестов простых ферм или механизмов. 
* Относитесь к тестам ответственно и не мешайте другим людям: [сервер Редстоун](./redstone.md) подходит для таких задач лучше.

### 2. Мир ивентов
* **Состав измерений**: Верхний мир, Незер и Энд.
* **Команда для перемещения в мир**: `/worldtp events` (или `/dimension events`).
* Мир, обслуживающий потребности Олимпийского комитета: для строительства, промежуточных тестов и субботников.
* Предоставлен почти полный функционал для отладки механизмов.
