# <span class="material-symbols-outlined">meeting_room</span> Сервер Лобби

* **Команда для перемещения**: `/lobby` (или `/lobby lobby`)

Сервер Лобби — промежуточный сервер для удобного перехода между мирами сети. Возможно, в будущем здесь будут реализованы какие-то активности.

---

## <span class="material-symbols-outlined">sync_alt</span> Перемещение между мирами

* На спавне установлены таблички, перемещающие вас в миры к которым у вас есть доступ (по нажатию ЛКМ или ПКМ по ним).
* Для быстрого перемещения между серверами доступна команда `/lobby <сервер>` (список серверов в [Обзоре серверов](./overview.md); команда без аргументов возвращает вас в лобби).
* Переход срабатывает только при наличии у игрока прав [доступа](../general/access.md) к выбранному миру.

```bash [Команды]
/lobby            # возврат в Лобби
/lobby <сервер>   # переход на указанный сервер
```
