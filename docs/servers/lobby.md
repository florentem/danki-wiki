# <span class="material-symbols-outlined">meeting_room</span> Сервер Лобби

* **Команда для перемещения**: `/lobby` (или `/lobby lobby`)

Сервер Лобби — транзитный сервер для удобного перехода между мирами проекта. Возможно, в будущем здесь будут реализованы какие-то активности.

::: tip Благодарность
Большое спасибо Берсу (`_bers_`) за прекрасное лобби, в том числе сезонные версии.
:::

---

## <span class="material-symbols-outlined">sync_alt</span> Перемещение

* На спавне установлены таблички, перемещающие вас в миры проекта, к которым у вас есть доступ (по нажатию ЛКМ или ПКМ по ним).
* Для перемещения на конкретный сервер проекта доступна команда `/lobby <сервер>` (список серверов в [Обзоре серверов](./overview.md); команда без аргументов возвращает вас в Лобби).
* Переход срабатывает только при наличии у игрока прав [доступа](../general/access.md) к выбранному миру.

```bash [Команды]
/lobby            # возврат в Лобби
/lobby <сервер>   # переход на указанный сервер
```
