# <span class="material-symbols-outlined">groups</span> Сервер Комьюнити

* **Команда для перемещения**: `/lobby community`

Основной сервер проекта. На сервере Комьюнити представлены следующие миры, различающиеся по правам использования команд и инструментов, специфике использования и получению доступа. Быстрое переключение между ними осуществляется командой `/worldtp <мир>` (алиас `/dimension`).

---

## <span class="material-symbols-outlined">public</span> 1. Основной мир, Мир артов и Архивы миров до миграции

### Основной мир
* **Состав измерений**: Верхний мир, Незер и Энд.
* **Команда для перемещения в мир**: `/worldtp main` (или `/dimension main`).
* Наследует основной мир до миграции на версию 26.2 (в сентябре 2026 г.).
* Предназначен в первую очередь для обычного строительства (например, построить дом для [Pepeland](https://www.pepeland.net) с другом или совместную постройку).
* Плохо подходит для тестов ферм и механизмов (для них предназначен [сервер Редстоун](./redstone.md)): необходимые для этого права и инструментал отсутствуют, чтобы ничего не мешало игрокам.

### Мир артов
* **Состав измерений**: только Верхний мир.
* **Команда для перемещения в мир**: `/worldtp art` (или `/dimension art`).
* Мир артов, идентичный по поведению мира и генерации (ячейки, повторяющие рамки карт) одноимённому миру с [Pepeland](https://www.pepeland.net).
* Карты, созданные здесь, можно переносить на все остальные серверы проекта через эндер-сундук (подробнее: [HuskSync](../features/features.md#husksync)).

### Архивные миры void и nosbworld
* **Состав измерений**: только Верхний мир в каждом.
* **Команды для перемещения в миры**:
  * `/worldtp void` (или `/dimension void`);
  * `/worldtp nosbworld` (или `/dimension nosbworld`).
* В проекте до миграции на версию 26.2 (в сентябре 2026 г.) было несколько миров («void» и «nosbworld»), отличавшихся от основного лишь генерацией. Сейчас они сохранены как архивные для [копирования и переноса построек](../general/requests.md#перенос-территорий-и-масштабных-построек), в случае если вы там что-то строили.
* Флагами и правами ограничено их редактирование — миры остаются неизменными.
* Предоставлен весь инструментарий для просмотра и копирования построек в другие миры.

## <span class="material-symbols-outlined">history_edu</span> 2. Архивные миры Pepeland

Официальные сейвы миров [Pepeland](https://www.pepeland.net), представленные на их сайте. Задумка заключается в удобном доступе к часто необходимым сейвам без загрузки их к себе на ПК.

### Представленные сезоны:
* **8 сезон**:
  * **Мир ферм** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-8 farm` (или `/dimension pepeland season-8 farm`).
  * **Мир построек 2** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-8 normal-2` (или `/dimension pepeland season-8 normal-2`).
* **9 сезон**:
  * **Мир ферм** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-9 farm` (или `/dimension pepeland season-9 farm`).
  * **Мир построек 2** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-9 normal-2` (или `/dimension pepeland season-9 normal-2`).
* **10 сезон**:
  * **Мир ферм** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-10 farm` (или `/dimension pepeland season-10 farm`).
  * **Мир построек 2** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-10 normal-2` (или `/dimension pepeland season-10 normal-2`).

### Особенности:
* Флагами и правами ограничено их редактирование — миры остаются неизменными.
* Предоставлен весь инструментарий для просмотра и копирования построек в другие миры.

## <span class="material-symbols-outlined">pets</span> 3. Мир «Кошкиного дома»

* **Состав измерений**: Верхний мир, Незер и Энд.

::: info Закрытый доступ
Мир для объединения «Кошкин дом», строительства ими построек для Pepeland и любых других задач.
Если вы не имеете прямых связей с этим объединением, скорее всего, этот мир вам не нужен. [Доступ](../general/access.md) выдаётся исключительно его участникам.
:::
