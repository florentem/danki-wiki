# <span class="material-symbols-outlined">groups</span> Сервер Комьюнити

* **Команда для перемещения**: `/lobby community`

Основной сервер проекта. На сервере Комьюнити представлены следующие миры, различающиеся по правам использования команд и инструментов, специфике использования и получению доступа. Быстрое переключение между ними осуществляется командой `/worldtp <подмир>` (алиас `/dimension`).

---

## <span class="material-symbols-outlined">public</span> 1. Основной мир, Мир артов и Архивы миров до миграции

### Основной мир
* **Команда для перемещения в подмир**: `/worldtp main` (или `/dimension main`).
* Наследует основной мир сервера до обновления на версию 26.2.
* Предназначен в первую очередь для обычного строительства (например, построить дом для [Pepeland](https://www.pepeland.net) с другом или командный проект).
* Плохо подходит для тестов ферм и механизмов (для них предназначен [сервер Редстоун](./redstone.md)): необходимые для этого права и инструментал отсутствуют, чтобы ничего не мешало игрокам.

### Мир артов
* **Команда для перемещения в подмир**: `/worldtp art` (или `/dimension art`).
* Мир артов, идентичный по поведению мира и генерации (ячейки, повторяющие рамки карт) одноимённому миру с [Pepeland](https://www.pepeland.net).
* Карты, созданные здесь, синхронизируются со всеми остальными серверами и мирами сети через эндер-сундук ([HuskSync](../features/features.md#husksync)) — достаточно заблокировать готовую карту в столе картографа и положить в эндерчест.

### Архивные миры void и nosbworld
* **Команды для перемещения в подмиры**:
  * `/worldtp void` (или `/dimension void`);
  * `/worldtp nosbworld` (или `/dimension nosbworld`).
* На сервере до миграции на версию 26.2 было несколько миров («void» и «nosbworld»), отличавшихся лишь генерацией. Сейчас они сохранены как архивные для [копирования и переноса построек](../general/requests.md#перенос-территорий-и-масштабных-построек), в случае если вы там что-то строили.
* Флагами и правами ограничено их редактирование — миры остаются неизменными.
* Предоставлен весь инструментарий для просмотра и копирования построек в другие миры.

## <span class="material-symbols-outlined">history_edu</span> 2. Архивные миры Pepeland

Официальные сейвы миров [Pepeland](https://www.pepeland.net), представленные на их сайте. Задумка заключается в удобном доступе к часто необходимым сейвам без загрузки их к себе на ПК.

### Представленные сезоны:
* **8 сезон**:
  * **Мир ферм** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-8 farm` (или `/dimension pepeland season-8 farm`).
  * **Мир построек 2** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-8 normal-2` (или `/dimension pepeland season-8 normal-2`).
* **9 сезон**:
  * **Мир ферм** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-9 farm` (или `/dimension pepeland season-9 farm`).
  * **Мир построек 2** (Верхний мир, Незер и Энд) — перемещение: `/worldtp pepeland season-9 normal-2` (или `/dimension pepeland season-9 normal-2`).
* Список будет расширяться в будущем по мере выхода сейвов 10-го и последующих сезонов.

### Особенности:
* Флагами и правами ограничено их редактирование — миры остаются неизменными.
* Предоставлен весь инструментарий для просмотра и копирования построек в другие миры.
