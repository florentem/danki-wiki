# <span class="material-symbols-outlined">extension</span> Плагины и моды

Плагины и моды, установленные на серверах проекта, с которыми напрямую взаимодействуют игроки (команды, моды, строительные инструменты и механики).

---

### [ArmorPoser](https://modrinth.com/project/PFwYNrHb)
Детальная настройка поз стоек для брони через интерфейс мода.

### [Axiom](https://modrinth.com/project/N6n5dqoA)
Не нуждается в представлении, весь функционал доступен на серверах. Документация есть на сайте разработчика: [axiomdocs.moulberry.com](https://axiomdocs.moulberry.com).

### [DreamDisplays](https://modrinth.com/project/4IIKQyBu)
Смешнючий мод, который позволяет смотреть видео с ютуба и не только прямо в игре. Команда: `/dreamdisplays:display`.

### [EasyArmorStands](https://modrinth.com/project/8DDI76SG)
Настройка и позиционирование стоек без установки мода с помощью команды (`/eas`).

### [GSit](https://modrinth.com/project/GOHbQGyX)
Возможность сидеть, лежать и ползать (`/sit`, `/lay`, `/crawl`).

### [HeadDB](https://modrinth.com/project/cRS8VY4i)
Каталог декоративных голов игроков и мобов для строительства (`/headdb`).

### [HuskHomes](https://modrinth.com/project/J6U9o3JG)
Система приватных точек дома (`/home`), публичных варпов (`/warp`) и межсерверной телепортации.

Краткая сводка команд:
* **Приватные точки дома** (до 200 на игрока): `/sethome <название>`, `/home <название>`, `/homes`, `/delhome <название>`.
* **Публичные варпы**: `/setwarp <название>`, `/warp <название>`, `/warps`, `/delwarp <название>`.
* **Телепортация и возврат**: `/tpa <игрок>`, `/tpahere <игрок>`, `/tpaccept`, `/tpdecline`, `/back`.

### [HuskSync](https://github.com/WiIIiam278/HuskSync)
Синхронизация содержимого эндер-сундука между серверами проекта для переноса предметов:
* Для переноса мап-артов заблокируйте готовую карту стеклянной панелью в столе картографа и положите в эндер-сундук.

### [ItemEdit](https://modrinth.com/project/yx81EHRu)
Редактирование предметов командами, идентичное [Pepeland](https://www.pepeland.net) (`/ie`).

### Кастомные модели (/model, /custommodel)
Команда смены моделей предмета в руке идентичная такой же с [Pepeland](https://www.pepeland.net):
* `/model <название>` — выбор модели из официального ресурспака Pepeland (с автодополнением по Tab). Для сброса — `/model reset`.
* `/custommodel <идентификатор>` — установка произвольной модели для личных ресурспаков (`/custommodel reset` для сброса).

### Навигация по серверам (/lobby)
Кастомный плагин для перемещения между серверами проекта:
* `/lobby` — возврат в [Лобби](../servers/lobby.md).
* `/lobby <сервер>` — прямое подключение к [серверу проекта](../servers/overview.md) при наличии прав доступа.

### Навигация по мирам (/worldtp, /dimension)
Команда для переключения между мирами текущего сервера (обратите внимание: алиас `/dimension` переключает именно миры, а не отдельные измерения):
* `/worldtp <мир>` (или `/dimension`) — переход в нужный мир (например, `main`, `art`, `events`, архивные сезоны [Pepeland](https://www.pepeland.net)). Отображаются те миры, к которым у вас есть доступ.

### [Ping Wheel](https://modrinth.com/project/QQXAdCzh)
Метки и указатели на местности по нажатию клавиши бинда, подобные играм (например, Portal).

### [Servux Plugin Edition](https://modrinth.com/project/b1qziGOa)
Серверная поддержка вставки и парсинга схематик мода [Litematica](https://modrinth.com/project/bEpr0Arc) без спама командами в чат, а также поддержка некоторых других функций Litematica и MiniHUD.

### [Simple Voice Chat](https://modrinth.com/project/9eGKb6K1)
Голосовой чат.

### [SnowballDamage](https://modrinth.com/project/3xJye6xI)
Отталкивание и урон от попадания снежками и яйцами (паритет с Pepeland).

### [WorldEdit](https://modrinth.com/project/1u6JkXh5)
Не нуждается в представлении.
